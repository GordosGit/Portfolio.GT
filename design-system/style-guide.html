GORD TURNER · PERSONAL BRAND

Off-World Cockpit design system.

The visual language behind gordturner.dev — a Blade Runner–inspired cockpit/panel aesthetic: void backgrounds, amber and cyan instrumentation, neon-pink identity accents, monospace + grotesk type. This page is the living reference. Copy tokens.css into any new HTML deliverable — a deck, a mockup, a one-pager — to match it exactly.

Amber = primary accent (CTAs, numbering, "agent" type). Cyan = secondary/technical accent ("skill" type, data readouts). Neon pink = identity only — your name, and the "these two things are chained together" marker. Gold is a rare highlight, not a workhorse color.
Don't introduce new accent colors per-deliverable. If a deck needs a fourth category color, reuse gold before inventing something new — five accent colors is already the outer edge of legible.

Using this in a new HTML deliverable

Every presentation, mockup, or one-pager for the brand should be a self-contained HTML file (open in any browser, no build step). Minimum boilerplate:

<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=IBM+Plex+Mono:wght@300;400;500;600&family=Space+Grotesk:wght@300;400;500;700&display=swap">
<style>/* paste tokens.css here, or <link> it if same-folder */</style>
<body class="brand-root">
  ...
</body>
For slide decks specifically: one <section> per slide, each roughly viewport-height, snap-scrolled or paginated with simple JS — see the site's own .section pattern for spacing rhythm. Cinematic chrome (rain canvas, film grain, the cursor-tracking eye, rotating kanji strip) belongs on a cover/title slide or the portfolio home — skip it on dense content slides where it would fight for attention with data or bullet points. Sec-head numbering (// 01, // 02…) doubles as a slide index if useful.
